# OnlyMonkes Privacy Policy

**Last updated:** March 2026

## Overview

OnlyMonkes is an NFT-gated social app for verified Saga Monkes holders. We are committed to protecting your privacy.

## Data We Collect

### Wallet Address
- Your Solana wallet public address is used solely to verify Saga Monkes NFT ownership via the Helius DAS API.
- Your wallet address is **never** stored on our servers.

### Messages
- All messages are end-to-end encrypted using the XMTP v5 MLS protocol.
- Messages are stored on the XMTP decentralized network — we cannot read your messages.
- We have no access to message content.

### Push Notifications
- An Expo push token is stored in your XMTP profile to enable push notifications.
- This token is used only to deliver notifications about new messages, mentions, and community activity.
- You can disable notifications at any time in your device settings.

### NFT Metadata
- Your selected Saga Monkes NFT image and metadata are cached locally on your device.
- This data is fetched from public on-chain sources (Helius DAS API, IPFS).

## Data We Do NOT Collect
- Private keys (we never have access to these — all signing happens in your wallet app)
- Personal identification information
- Location data
- Device identifiers beyond the push notification token

## Third-Party Services
- **XMTP**: Decentralized messaging protocol — see https://xmtp.org/privacy
- **Helius**: NFT verification via DAS API — see https://helius.dev/privacy
- **Cloudinary**: Video hosting for in-chat videos — see https://cloudinary.com/privacy
- **LiveKit**: Live audio infrastructure — see https://livekit.io/privacy
